---
title: Keyboard Shortcuts
description: Complete reference of every keyboard shortcut in Rosewood
---

Rosewood is keyboard-first. Every action has a shortcut — this page is the complete reference.

## File

| Shortcut | Action |
|----------|--------|
| `⌘N` | New File |
| `⌘O` | Open File |
| `⌘⇧O` | Open Folder |
| `⌘S` | Save |
| `⌘⇧S` | Save As |
| `⌘⌥S` | Save All |
| `⌘W` | Close Tab |
| `⌘⇧T` | Reopen Closed Tab |

## Navigation

| Shortcut | Action |
|----------|--------|
| `⌘P` | Quick Open (files, lines, symbols) |
| `⌘⇧P` | Command Palette |
| `⌘L` | Go to Line |
| `⌘1` – `⌘9` | Go to Tab N |
| `⌘⇧]` / `⌘⇧[` | Next / Previous Tab |
| `F12` | Go to Definition |
| `⇧F12` | Find References |
| `F8` / `⇧F8` | Next / Previous Problem |

## Search

| Shortcut | Action |
|----------|--------|
| `⌘F` | Find in File |
| `⌘⌥F` | Find & Replace in File |
| `⌘⇧F` | Find in Project |
| `⌘E` | Use Selection for Find |

## Editing

| Shortcut | Action |
|----------|--------|
| `⌘/` | Toggle Line Comment |
| `⌥↑` / `⌥↓` | Move Line Up / Down |
| `⌘⇧D` | Duplicate Line |
| `⌘⇧K` | Delete Line |
| `⌃⇧J` | Join Lines |
| `⌘Z` / `⌘⇧Z` | Undo / Redo |
| `Tab` / `⇧Tab` | Indent / Outdent Selection |

## View

| Shortcut | Action |
|----------|--------|
| `⌘=` / `⌘-` | Zoom In / Out |
| `⌘0` | Actual Size |
| `⌃⌘F` | Toggle Full Screen |
| `` ⌃` `` | Toggle Terminal |
| `⌘,` | Settings |

## Window

| Shortcut | Action |
|----------|--------|
| `⌘⇧N` | New Window |
| `⌘M` | Minimize |

:::tip[Custom shortcuts]
Shortcuts follow macOS conventions. Menu items show their current key equivalents, and `validateMenuItem` keeps them contextually enabled.
:::
